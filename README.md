# TI-84 Utilities

## Description
Within this repo are six quality-of-life programs for the TI-84 Plus CE calculator.
Included functions:
- Modulo Operation
- Quadratic Formula
- Dice Roll Simulator
- Distribution of N Items into M Containers
- Binary to Decimal Converter (16 bit)
- Decimal to Binary Converter (16 bit)

## Installation
Simply `git clone` this repo and use a tool such as TI-Connect or TiLP2 to transfer the files to a connected TI-84 Plus CE calculator. \
```git clone https://github.com/CR4SH-L4NDING/TI84-Utils```
